Current knowledge-source directory and authority

This is an unofficial staff-developed reference. The full legacy reference text below is preserved from the forwarded “index GitHub” email. It is historical/reference material, not a competing set of current permanent agent instructions. Current AACPS policy, verified instrument manuals, and evaluating OT judgment govern where applicable.

  1. Copilot_Execution_Guide_GitHub.md — Execution Guide — workflow, section order and quality checks
  2. Approved_Language_Bank_GitHub.md — Approved Language Bank — evidence-supported phrasing and verified standard wording
  3. Assessment_Guidance_GitHub.md — Assessment Guidance — instrument-specific reporting and score handling
  4. OT_Copilot_Handbook_Machine_Optimized_GitHub.md — Machine-Optimized Handbook — comprehensive clinical reference and historical examples

Source precedence: Agent permanent instructions and current district requirements govern; Execution Guide controls report workflow; Assessment Guidance controls assessment-specific guidance; Approved Language Bank supplies evidence-supported wording; Machine-Optimized Handbook provides additional examples and comprehensive context. Never infer that a public GitHub link is successfully indexed in Copilot: verify retrieval in the agent.

Current report headings: Purpose of Assessment; Socio-Cultural or Linguistic Considerations; Validity Statement; Background Information; Assessment Procedures; Test Scores; Assessment Results; Factors Influencing Assessment Results; Strengths and Needs as Related to Classroom Performance; Data Analysis; Summary of Findings; Instructional Implications.

Historical assessment references: Legacy mentions of original Sensory Profile/SPM, PDMS-2, SSC-SV or other tools do not establish current district approval. Use only instruments actually administered and currently authorized; do not invent scores, classifications, or exact approved language. Preserve original notes and flag unresolved facts.

Privacy: Do not publish student-identifiable data or restricted/copyrighted materials to a public GitHub repository.
