# Assessment Guidance — AACPS OT Copilot Knowledge Hub

> **Status:** Staff-developed operational guidance. Not an official AACPS policy document. The evaluating OT verifies all content. Never publish identifiable student information or restricted district resources to a public repository.

## Purpose
Guide the agent in organizing therapist-supplied assessment data without replacing clinical reasoning. All observations, scores and interpretations must be attributable to supplied information or authorized sources.

## Evidence capture checklist
- Student identifier/name exactly as entered (only in approved protected system).
- Referral/evaluation type and question, when known.
- Procedures actually completed, location(s), date(s), participant(s), supports and testing conditions.
- Standardized tool name/edition, respondent/form, reported scores, classifications and limitations.
- Classroom observation, work samples, interviews, functional tasks, teacher/caregiver perspectives and record review, only if actually completed.
- Strengths, difficulties, contextual factors and participation implications supported by evidence.

## Procedures versus results
**Assessment Procedures:** describe how information was gathered. Include only completed procedures; insert approved descriptions after relevant standardized test names. No interpretation.

**Test Scores:** preserve all numeric values and labels exactly. Do not generate missing percentiles or convert scores without explicit authorization and verified norms.

**Assessment Results:** preserve detailed observations and organize them under relevant domains:
1. Neuromuscular/Postural
2. Manipulation Skills
3. Response to Learning Environment
4. Pencil Grasp and Handwriting
5. Classroom Skills
6. Visual / Visual-Perceptual Skills
7. Occupational Performance and Functional Participation
Use the handbook's narrative → lead-in → bullet observations → summary pattern. Include only domains actually supported.

## Assessment-specific reporting considerations
- **Beery VMI:** report exactly the administered components and scores; distinguish visual-motor integration from any separately administered visual-perception or motor-coordination measures.
- **Sensory Profile 2:** identify the actual form/respondent, reported patterns and domain findings. Do not treat rating-scale results as direct observation.
- **SPM-2:** identify actual form/respondent, scales and reported score interpretations. Distinguish informant perceptions from direct performance.
- **Other measures:** use current approved descriptions and the actual edition; do not infer an assessment was administered from a mention of its name.

## Cross-section synthesis map
| Source fact | Primary location | Appropriate later use |
|---|---|---|
| Standardized score | Test Scores | Interpret in Data Analysis and Summary only with supported context |
| Observable fine-motor performance | Assessment Results | Strengths/Needs, Summary, Instructional Implications |
| Participation, fatigue or environmental supports | Factors Influencing Assessment Results | Qualify interpretation in Data Analysis/Summary |
| Classroom task performance | Assessment Results | Educationally relevant Strengths/Needs and implications |
| Caregiver/teacher report | Background/Results as appropriate | Synthesize with attribution; note disagreement with direct observation |

A single fact may inform several sections; the therapist must not reenter it. Synthesize, do not paste identical wording repeatedly.

## Instructional implications
Present bulleted strategies only when findings support them. Examples for consideration (not automatic recommendations): visual schedules, first/then cues, adapted writing paper, slant boards, movement breaks, environmental noise adjustments, task modifications and self-care practice. The evaluating therapist decides appropriateness; do not prescribe services or eligibility.

## Handling uncertainty
Use `[THERAPIST INPUT REQUIRED: ...]` for absent facts, `[THERAPIST SELECTION REQUIRED: ...]` for approved alternatives, and `[APPROVED LANGUAGE NOT RETRIEVED — VERIFY KNOWLEDGE SOURCE]` when verbatim text is inaccessible. Avoid unnecessary preliminary questioning; draft all 12 sections on request.

## Final review and confidentiality
Check fidelity to source, test score transcription, consistency across sections, supported educational relevance, exact formatting and final AI disclosure. Use protected AACPS-approved systems for student-specific information. Public GitHub must not contain identifiable student records or restricted materials.
